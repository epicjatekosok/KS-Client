# KS Client

KS Client is an unofficial Windows desktop client for Kirka.io. It is an independent community project and is unaffiliated with the game's developers.

It includes a self-contained Electron runtime, graphics and frame-rate controls, a customizable interface and Workshop, public KirkaStats profiles and clan standings, skin price estimates, regional server counts, and a verified update channel.

## Downloads

Get the Windows x64 Setup EXE or Portable ZIP from [KS Client releases](https://github.com/epicjatekosok/KS-Client-Updates/releases). The ready-to-run packages include Electron and require no separate Node.js installation. The Portable ZIP starts through `KS-Client.exe` after extraction.

For development, download the release asset named `KS-Client-beta-<version>-Source.zip`. This archive contains the source for the Windows packages. GitHub's autogenerated **Source code** links download the public updates repository instead. Each release also provides a SHA-256 file for the KS Client source archive.
