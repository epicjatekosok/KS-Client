# KS Client Beta 1.0.30

- The lobby's Client Download slot opens the KS Discord server. The neighboring slot opens KS Client Settings. Both are keyboard accessible. The game's gear still opens Kirka Settings, with an additional KS Client shortcut in its tabs.
- Choose a local CSS file or KS theme JSON in Interface → Appearance or CSS Editor, or drag it onto the import card. Preview the result immediately, apply to save, or cancel to restore the previous look. CSS files up to 256 KiB are supported.
- Discord desktop activity follows the game process, retries when Discord starts later, and reports whether Discord acknowledged the activity. A registered public Discord Application ID is required. When no distributor ID is configured, Advanced → General accepts a local ID. Discord's activity privacy setting still applies.
