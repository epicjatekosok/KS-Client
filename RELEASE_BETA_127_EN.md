# KS Client Beta 1.0.27

This release includes the MIT-licensed KS Client source, Windows build instructions, contribution guidelines, security reporting instructions and third-party notices. Use the attached **KS-Client-beta-1.0.27-Source.zip** and **KS-Client-beta-1.0.27-Source.sha256.txt** to inspect and verify the client source.

Windows x64 users can download the offline Setup EXE or Portable ZIP and update through the existing Beta channel. GitHub Actions checks the archived commit, scans the source and builds and tests the Windows packages from the extracted source archive. The manifest lists the artifact hashes and the signing report records Authenticode status.
