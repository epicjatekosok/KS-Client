# KS Client Beta 1.0.31 • Rendering test build

Game callbacks run on Chromium animation frames. The limiter coalesces requests and sleeps between frames at lower targets. Above-refresh fixed targets and Unlimited can request unlocked Chromium scheduling after restart. Monitor mode follows the current display. The hardware, driver, game engine and Windows presentation mode determine actual throughput.

Choose performance and graphics quality independently. Inspect active adapters, backend and monitor in Diagnostics. Check optional backends per machine. Frame Stability can capture callback intervals during a match. Compare those results with the Windows PresentMon tool. GPU utilization, displayed FPS and latency gains require hardware measurements.
