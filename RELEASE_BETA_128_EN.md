# KS Client Beta 1.0.28

- Open **Workshop → KS Analytics** for foreground play time, menu time, regional totals, session history, and day/week/month charts. Results are counted when the visible match changes to the results screen. Durations describe observed play, including a partial match when joining late. Export or reset local history here.
- Open **Workshop → Resource Swapper → Workshop Gallery** to browse, preview, favorite, import and manage local and shared media packs. Use an exact observed asset path, enable both the pack and the main swapper, and reload the game. Audio gain and mute produce a PCM replacement for the selected sound. Factory sounds return when the file or pack is disabled, subject to overlapping packs. Shared packs are local imports.
- Player inventories in KirkaStats support price ranges, favorites and sorting. Estimates use available trader data. Clan search is reachable from Friends & Profiles. A rank badge needs a published rank. KS cosmetic badges and gradients only affect local presentation.
- Lobby links to regional HTTP request timings, timestamps and unavailable states. These measure a room-list request and do not report gameplay network ping.
- Plugins accept local JS, scoped CSS and KS manifests with author, description, category and permissions. Scripts still require manual launch. Scoped CSS accepts only listed selectors and hex colors. Configure shortcuts in **Gameplay → Game Integration**. Theme palettes can be shared through **Interface → Appearance → Shared themes**.
- Weapon Studio supports named transform presets, a reference-model preview and JSON interchange. Verified live Kirka first-person model ownership is unavailable. The new editor does not apply poses to live match geometry. Existing exact-texture cosmetics remain available.

## Manual verification on a signed-in account

Check more than one match and restart KS. Compare a known owned inventory with its public valuation, test exact image and audio substitutions on two weapons, then disable them and reload. Compare the same scene with Settings closed and open on the same hardware. No hardware FPS or power improvement is claimed for this update.
