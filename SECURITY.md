# Security policy

Use the newest Beta release for security testing. Report suspected vulnerabilities privately to a KS Client maintainer by direct message through the [KS Client community](https://discord.gg/cxP386yGjk). Use a public issue only to request private contact, without technical details.

Include the affected version, security impact, safe steps to reproduce and any useful redacted logs. Keep credentials, cookies, browser profiles, signing material and other users' personal data out of reports. Please allow time to investigate and release a fix before publishing details.

Reports about Kirka.io itself should go to the game's own maintainers.
