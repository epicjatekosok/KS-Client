# KS Client Beta 1.0.23

- Moved **Display language** to **Settings → Interface → Interface**. Added Hindi, Bengali, Indonesian, Korean, and Turkish translations for the main client interface and common settings. Some advanced labels remain in English.
- Added a localized reminder to restart KS Client when turning Unlimited FPS back on after disabling it or changing the FPS limit. Restarting KS Client also restarts the game.
