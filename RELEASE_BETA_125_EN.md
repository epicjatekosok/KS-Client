# KS Client Beta 1.0.25

- Workshop accepts local skin images and stores up to eight exact weapon texture bindings. A matching game texture upload is required. Reload the game after changing already uploaded textures.
- Search observed inventory, market listings and friends. Compare visible prices by currency and track changes to the lowest observed asking price locally. Add personal player tags and favorites.
- Create, import, export and prioritize passive resource packs. Imported packs start disabled. The original loose-file swapper remains available.
- Plugin API 2 adds manually started isolated workers with settings, text panels, limited events and a watchdog. Legacy plugin previews and saved profiles continue to work.
- Fixed-target pacing can skip intermediate monitor wakeups. On supported game screens, the client can apply an exact FPS target through a visible native game selector. A Windows measurement tool is included. A universal driver limit and power savings are unverified.
