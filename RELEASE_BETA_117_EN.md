# KS Client Beta 1.0.17

- Open Kirka’s Friends list and search by nickname or player ID. Search ignores case and accents.
- Open the Servers list to search the room rows or hide rooms that Kirka marks as locked. Clearing the filters restores the native list. The game keeps control of Join and Spectate.
- Both list tools stay in the game menu and follow changes to the loaded rows. Toggle **Search game lists** in **Game Integration**.
- A friend’s Spectate shortcut follows their current room when Kirka reuses a friend row. It disappears when the friend goes offline.
- Enable **F2 screenshot** in **Game Integration** to save a game-window PNG in Pictures/KSClient without opening Settings. The shortcut is off by default and yields to text entry.

Both Electron and CEF use these controls. List tools require compatible HTML from Kirka.
